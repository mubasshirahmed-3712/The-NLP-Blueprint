# 🧠 NLTK-Playground: Interactive NLP Explorer  

> 🔎 *"Learn and explore NLP fundamentals with an interactive Streamlit app."*  

---

## 📌 Project Overview
**NLTK-Playground** is a mini-project built with **Streamlit + NLTK** that allows users to **interactively explore NLP basics** such as:  
- Tokenization  
- Stopword Removal  
- Part-of-Speech Tagging  
- N-Grams (Bigrams, Trigrams, Custom N-Grams)  
- Stemming (Porter, Lancaster, Snowball)  
- Lemmatization  

This project acts as a **learning tool** for students, beginners, and NLP enthusiasts to understand how natural language processing works step by step.  

---

## 🎯 Objectives
- Provide an **interactive way** to test NLP techniques.  
- Compare different stemming and lemmatization methods.  
- Generate **n-grams** dynamically for deeper text analysis.  
- Showcase the integration of **NLTK with Streamlit** for real-time exploration.

## ⚙️ Installation & Usage

1️⃣ **Clone this repository**  
```bash
git clone https://github.com/mubasshirahmed-3712/AI-FSDS-progress-journal.git
cd Natural_Language_Processing/15_Projects/02_NLTK_Playground
```

2️⃣ **Install dependencies**  
```bash
pip install -r requirements.txt
```

3️⃣ **Run the app**  
```bash
streamlit run app.py
```

4️⃣ Open your browser → Streamlit will launch at `http://localhost:8501`
